Pré-identificação de árvores com QGIS, GeoAI e DeepForest

1. O que estamos chamando de pré-identificação?

Pré-identificar é marcar, a partir de uma imagem aérea, onde provavelmente existe uma árvore. Isso não substitui campo. Uma detecção automática é um candidato que ainda precisa ser confirmado.

Fluxo recomendado: ortofoto → detecção automática → filtro de falsos positivos → revisão visual → pontos centrais → UUID/ID → GeoJSON → CPF Verde → validação em campo.

Há dois erros principais: falso positivo (telhado, carro, arbusto etc. chamado de árvore) e falso negativo (árvore real que o modelo não marcou). O método precisa tratar os dois.

2. O que você precisa

  • QGIS 3.x; no piloto foi usado QGIS 3.42.1 Münster.
  • Plugin GeoAI.
  • Ortofoto/ortomosaico georreferenciado.
  • Tempo para revisão visual.
  • Conhecimento básico de QGIS. Para problemas de dependências, ajuda ter alguma familiaridade com linha de comando ou usar uma IA como apoio.
Os parâmetros do piloto não são universais. Eles funcionaram naquela imagem, naquela resolução e naquela paisagem urbana.

3. Ortofoto, ortomosaico e resolução

Ortofoto é uma fotografia aérea corrigida geometricamente. Ortomosaico é o conjunto de várias imagens corrigidas e unidas.

No piloto de Cáceres, a imagem original tinha cerca de 3 cm/pixel. Isso era excelente para visualização, mas o modelo fragmentava copas em várias caixas. Criamos uma cópia em aproximadamente 10 cm/pixel, preservando o original.

ResoluçãoSignificadoUso
0,03 m3 cm/pixelimagem original detalhada
0,06 m6 cm/pixelteste intermediário
0,10 m10 cm/pixelboa referência inicial no piloto
0,15 m15 cm/pixelteste quando há fragmentação excessiva

No QGIS: Raster → Projeções → Reprojetar (Warp). Para reduzir uma imagem RGB, use Média/Average e informe a resolução desejada nas unidades do SRC.

4. Preparando o QGIS e o GeoAI

  1. Abra Complementos → Gerenciar e instalar complementos.
  2. Procure GeoAI e instale.
  3. Abra o menu GeoAI e instale as dependências na primeira execução.
  4. Se o plugin solicitar, reinicie o QGIS.
  5. Para árvores, use GeoAI → Tree Segmentation.
CPU funciona. Sem GPU o processo é mais lento, mas o piloto foi executado em CPU. Batch Size 1 é uma escolha segura.

5. Prepare o raster antes da IA

5.1 Comece por uma amostra

Recorte algumas quadras com árvores grandes, pequenas, agrupadas, sombras, telhados e carros. Calibre antes de processar uma área extensa.

5.2 Confira o SRC

Abra Propriedades → Informação. Para o piloto de Cáceres, o fluxo final usou SIRGAS 2000 / UTM 21S — EPSG:31981.

5.3 Salve o GeoTIFF como TILED

Em Converter formato/Translate, use:

TILED=YES
COMPRESS=DEFLATE

O segundo item é opcional; TILED=YES é o que permite leitura por janelas no Large Tile.

6. Detecte com DeepForest

  1. GeoAI → Tree Segmentation.
  2. Carregue weecology/deepforest-tree.
  3. Escolha o raster preparado.
  4. Para imagens maiores, escolha Large Tile.
  5. Execute e salve o resultado vetorial permanentemente.

Configuração que funcionou razoavelmente no piloto:

ParâmetroValor do piloto
Patch Size848
Patch Overlap0,25
IoU Threshold0,15
Batch Size1
Dataloaderwindow
Score Threshold0,14

7. Entenda os parâmetros

Patch Size

Quanto da imagem o modelo enxerga de cada vez. Muito pequeno pode fragmentar copas e perder contexto; muito grande pode deixar árvores pequenas menos evidentes.

Score Threshold

Confiança mínima aceita. Baixar o valor aumenta a sensibilidade e também os falsos positivos. Aumentar deixa o resultado mais limpo, mas pode perder árvores.

Patch Overlap

Sobreposição entre patches. Ajuda a não cortar árvores nas bordas.

IoU Threshold

Controla a remoção de caixas muito sobrepostas. Valores menores eliminam redundâncias de forma mais agressiva.

Batch Size

Número de patches processados juntos. Em CPU, mantenha 1 se houver dúvida.

Mude uma variável por vez. Se você altera tudo simultaneamente, não aprende qual ajuste realmente ajudou.

8. Use RGB/ExG para encontrar falsos positivos

Em imagens RGB, calcule o Excess Green:

ExG = 2 × Green − Red − Blue

Na Calculadora Raster:

2 * "imagem@2" - "imagem@1" - "imagem@3"

Depois use Estatísticas zonais para calcular a média do ExG em cada caixa.

Use três classes:

ClasseInterpretação
ARVOREárvore clara
NAO_ARVOREtelhado, carro, chão, planta fora do escopo etc.
REVISARcaso realmente ambíguo
ExG não resolve falso negativo. Ele só classifica o que o DeepForest já detectou. No piloto, quase todos os baixos ExG eram realmente não árvores, com uma exceção importante: uma palmeira.

9. Faça a revisão manual

Mantenha duas versões:

  • ..._naorefinado — saída automática original.
  • ..._refinado — falsos positivos removidos e árvores omitidas adicionadas.

Para remover um erro, edite a camada, selecione a feição e pressione Delete. Para uma árvore omitida, desenhe uma nova feição.

Crie o campo origem:

IA      = detectada automaticamente
MANUAL  = adicionada durante a revisão

Não apague a versão automática; ela é útil para avaliar desempenho.

10. UUID e ID público

UUID

Crie um campo texto com espaço suficiente e preencha uma única vez com:

uuid()

Não regenere esse UUID em futuras campanhas.

ID público

No piloto foi usado:

ARB-31981-X-Y-XXXX

Exemplo: ARB-31981-426877-8223415-D206. O ID público deve permanecer estável mesmo se a posição for refinada depois.

11. Transforme as caixas em pontos

No CPF Verde, o objeto principal é o ponto da árvore.

  1. Caixa de Ferramentas → Centroides.
  2. Entrada: camada refinada.
  3. Salve como GeoPackage, por exemplo pre_cadastro_arvores_pontos.gpkg.
  4. Confira se uuid, id_publico e origem vieram junto.

Crie x_utm e y_utm com $x e $y. Para a web, a geometria final será exportada em EPSG:4326.

O centroide é uma posição estimada. Uma copa assimétrica pode ter o tronco alguns metros longe do centro geométrico. Por isso o CPF Verde mostra um halo até a validação em campo.

12. Exporte o GeoJSON para o CPF Verde

  1. Botão direito na camada de pontos → Exportar → Guardar elementos como...
  2. Formato: GeoJSON.
  3. SRC de saída: EPSG:4326 — WGS 84.
  4. Codificação: UTF-8.
  5. Geometria: Point.
  6. Salve com extensão .geojson.

Campos recomendados: uuid, id_publico, origem, x_utm, y_utm, longitude, latitude e score quando existir.

No CPF Verde: Dados → Importar pré-identificação. Confira a prévia e importe somente novos. Os pontos entram como PRE_IDENTIFICADA e não entram nas estatísticas de árvores já avaliadas.

13. Erros comuns e soluções

GeoAI/DeepForest não carrega

Geralmente é incompatibilidade de dependências. Gere diagnóstico e confira versões antes de editar arquivos manualmente.

predict_tile() got an unexpected keyword argument 'path'

É incompatibilidade entre GeoAI e DeepForest. Ajuste a versão do ambiente/modelo.

raster is not tiled

Converta com TILED=YES.

Processamento lento

Use uma amostra menor, teste resolução reamostrada e ajuste Patch Size.

Copas fragmentadas

Teste resolução menos fina e/ou Patch Size maior.

Muitas árvores faltando

Teste Patch menor e Score menor, sabendo que virão mais falsos positivos. Complete manualmente as omissões restantes.

UUID cortado

O campo texto era curto. Crie outro com comprimento suficiente e gere o UUID completo.

GeoJSON não aparece

Confira o caminho real. .gpkg não é GeoJSON. Exporte explicitamente para .geojson.

Ponto parece deslocado

Compare com imagem aérea. Mapas vetoriais e imagens de datas diferentes podem estar alguns metros deslocados. Não mova o ponto só para encaixar em uma rua desenhada.

14. Checklist final

  • ☐ A camada final contém apenas candidatos válidos.
  • ☐ Árvores omitidas foram adicionadas.
  • ☐ A origem está marcada como IA ou MANUAL.
  • ☐ Cada árvore possui UUID completo e único.
  • ☐ Cada árvore possui ID público estável.
  • ☐ A geometria final é Point.
  • ☐ O GeoJSON foi exportado em EPSG:4326.
  • ☐ O arquivo termina em .geojson.
  • ☐ A prévia no CPF Verde foi conferida.
  • ☐ Os parâmetros da campanha foram registrados.
Um bom pré-cadastro é reproduzível. Outra pessoa deve conseguir entender de onde vieram os pontos, quais parâmetros foram usados e o que foi corrigido manualmente.
